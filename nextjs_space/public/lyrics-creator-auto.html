Output and input

Settings

When enabled, Enter records a syllable and starts the next lyric line with that tap. When disabled, Enter only starts the next line.

When enabled, checks that generated lyrics match the rhythm pattern. Extra or missing syllables are marked in red. Off by default.

50ms

When “Say syllables out loud” is on, the browser voice starts this many milliseconds before each tap, to cover TTS delay. Default 50ms. Uses the device’s built-in voices. English voices cannot speak Malayalam or other non-Latin scripts — install that language’s speech voice in Windows if Test voice is silent.

100%

Volume of the uploaded track in this tab. Turn this down if the spoken syllables are hard to hear over the music.

100%

Volume of the spoken lyrics. That voice is separate from the waveform and may use a different Windows output device. Test voice speaks a sample in the lyric language (or Target Language). If Malayalam stays silent, install a Malayalam speech voice in Windows Settings → Time & language → Speech.

500ms

When enabled, subtracts this delay from each tap so markers line up with what you heard. Use ~500ms for many Bluetooth headphones. Off by default.

100ms

Extra offset applied when playback is running, for human reaction time and app processing. Default 100ms.
